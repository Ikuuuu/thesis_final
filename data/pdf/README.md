# 원본 법령 PDF (41건)

국가법령정보센터(https://www.law.go.kr)에서 내려받은 현행 법령 PDF입니다. 법령 원문은 「저작권법」 제7조에 따라 자유롭게 이용할 수 있지만, 용량과 배포 환경 문제로 저장소에는 PDF를 넣지 않았습니다.

## 준비 방법

1. 국가법령정보센터에서 아래 법령을 검색해 본문 화면의 **PDF 저장**으로 내려받습니다.
2. 파일명을 `제목(법령종류)(제N호)(시행일).pdf` 형식으로 이 폴더에 둡니다. 파서가 파일명에서 법령종류·공포번호·시행일을 읽습니다.
3. PDF 없이도 파싱 결과(`data/raw/*.json`)와 KG 데이터셋은 저장소에 들어 있어 이후 단계는 바로 실행할 수 있습니다.
